Tareas

Entregables y documentación estructurada.

Tarea 1: Configuración del entorno de trabajo

Documentación paso a paso de la instalación de WSL, Ubuntu, Docker Engine, zsh, pyenv y Jupyter Notebook para preparar el entorno del curso de AWS Data.

Tarea 2: Estadísticas básicas en Python

Función propia para calcular media, mínimo y máximo de una lista de números, y filtrado de valores por encima del promedio.

Tarea 3: Estadística descriptiva con el metodo describe()

Explicación conceptual de los métodos que genera describe() en Pandas (count, mean, std, min, percentiles, max) y qué mide cada uno estadísticamente.

Tarea 4: Análisis exploratorio con Pandas

Exploración del dataset del Titanic (vía Kaggle) para obtener estadísticas descriptivas de edad y conteo de pasajeros.

Tarea 5: Análisis de Órdenes de Chipotle con NumPy y Pandas

Exploración del dataset público de pedidos de Chipotle: producto más pedido, número de órdenes, ventas totales, precio promedio por orden e ítems distintos vendidos.

Tarea 6: Visualización de datos con Matplotlib

Limpieza y análisis del dataset de Spotify 2023 leído desde S3, con gráficas de barras, dispersión, histogramas, pastel, caja y correlación entre variables.

Tarea 7: Ingesta de datos a S3 (NYC TLC)

Script de descarga automatizada de los datos de viajes de taxis de Nueva York (yellow, green, fhv, fhvhv) y carga organizada por año/mes en un bucket S3..

\

Tarea 8: Análisis de ventas E-commerce (Olist)

Integración de múltiples datasets desde S3 (órdenes, clientes, productos, pagos, reseñas) para responder preguntas de negocio: estados con más ventas, ticket promedio, categorías top, métodos de pago y correlación entre tiempo de entrega y calificación.
