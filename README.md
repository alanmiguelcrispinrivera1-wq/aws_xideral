## 🎯 Sobre el Repositorio

Este repositorio es un espacio dedicado a la exploración, despliegue y automatización de arquitecturas en la nube dentro del ecosistema de Amazon Web Services (AWS). 

En este espacio se consolidan proyectos prácticos, ejercicios, pipelines de datos y configuraciones de sistemas, con el objetivo de aplicar buenas prácticas de DevSecOps y Data Engineering.

### Casos de Uso y Áreas de Enfoque:
- **Cloud Infrastructure:** Despliegue seguro y escalable en AWS.
- **DevSecOps & Automatización:** Contenedorización con Docker/Kubernetes, gestión de configuración e implementación de CI/CD mediante GitHub Actions.
- **Data Engineering:** Limpieza y procesamiento de datos utilizando Python (Pandas, NumPy, PySpark) y visualización en Streamlit.
- **Administración de Sistemas:** Scripts de automatización en Bash y PowerShell.

---

## 🛠️ Stack Tecnológico

El desarrollo de los proyectos de este repositorio involucra las siguientes tecnologías:

- **Cloud Provider:** Amazon Web Services (S3, EC2, etc.)
- **DevOps:**  Docker, Kubernetes, Git, GitHub Actions.
- **Sistemas Operativos:** Linux (Ubuntu).
- **Lenguajes de Scripting/Programación:** Python, Bash, PowerShell, SQL.
- **Bases de Datos:** MySQL.
- **Datos y Visualización:** Pandas, NumPy, Matplotlib, Jupyter Notebook, Streamlit.
